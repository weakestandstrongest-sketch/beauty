# 候 KŌ

勉強や作業のあいだ、画面に開いておくための一枚の絵です。
下のガラスのバーで、左の「候」（七十二候の時計）と、右の「遊」（1台をふたりで遊ぶ8つのゲーム）を切り替えます。
機能は最小限にとどめ、見た目を優先して作っています。

公開ページ: https://weakestandstrongest-sketch.github.io/beauty/

ビルドは不要です。「遊」は ES Modules なので、手元で確かめるときは `file://` ではなくサーバー経由で開いてください。

```sh
python3 -m http.server 8000   # http://localhost:8000
npm test                      # ゲームのルール部分のテスト
```

## GitHub Pages での公開

リポジトリの **Settings → Pages** で、このブランチのルートから公開する設定になっています。
プッシュするたびに自動で反映されます。`.nojekyll` は Jekyll の変換を止めて、ファイルをそのまま配信するためのものです。

## 見どころ

- **七十二候に合わせて変わる画面** 今日がどの候かを計算し、その名前を縦書きで表示します。たとえば 10/28〜11/1 は「霎時施（こさめときどきふる）」です。
- **節気ごとの伝統色** 二十四節気ごとに伝統色をひとつ決め、その色で背景の絹のような流体（WebGL）を染めます。
- **時刻で変わる明るさ** 昼は明るく、夜は暗く沈みます。
- **候ごとの天気** 雨、雪、花びら、紅葉、蛍、霜のきらめきが画面を舞います。
- **季節で色が変わるアイコン** タブのアイコンは、絹の上に線一本と判子を置いた形で、その節気の色に染まります。

## 遊（あそび二人用）

iPhone 1台をふたりで使うゲーム集です。もとは [あそび2人用](https://github.com/weakestandstrongest-sketch/asobi) で、ルールはそのままに、見た目を候に合わせて作り直しました。
盤や升目の色は、背景の絹と同じく今の節気の色に合わせて変わります。

| ゲーム | 内容 |
| --- | --- |
| ヨット | サイコロ5つ・3回まで振って12の役を埋める |
| ヒット&ブロー | おたがいの秘密の色4つを交互に推理する |
| 五目並べ | 15路盤。禁じ手なし / あり |
| リバーシ | 置ける場所の表示、自動パス |
| チェス | キャスリング、アンパッサン、昇格、引き分けの各ルール |
| 5五将棋 | 持ち駒、成り、二歩・打ち歩詰めの禁止、千日手 |
| エアホッケー | マルチタッチで二人同時に操作 |
| ダーツ | 盤を押すと照準が出て、離すと投げる。照準は手ぶれのように揺れ、長く押すほど大きく揺れる。カウントアップ / 301 / 501 |

メニューの「向かい合わせ」をオンにすると、テーブルをはさんで座ったとき上側の人の表示が逆さになります。

- `js/asobi/games/*-logic.js` … 各ゲームのルール（DOM に依存しない。`tests/` にテスト）
- `js/asobi/games/*.js` … 各ゲームの画面
- `js/asobi/ui.js` … 共通の部品・設定・効果音
- `css/asobi.css` … 遊の見た目

## 操作

| キー | 動作 |
| --- | --- |
| 1 / 2 | 候 / 遊 に切り替え |
| ← → | ほかの候をめくって見る（「今」で戻る） |
| H | 文字を隠して絵だけにする |
| F | 全画面表示 |

開いた直後のオープニングは、クリックかキーを押すと飛ばせます。

「Now, I am」の後ろの一行はクリックして書き換えられます。内容はブラウザに保存されます。

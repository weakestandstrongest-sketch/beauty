# 候 KŌ

勉強や作業のあいだ、画面に開いておくための一枚の絵です。
機能は最小限にとどめ、見た目を優先して作っています。

`index.html` をブラウザで開くだけで動きます。ビルドは不要です。

## 見どころ

- **七十二候に合わせて変わる画面** 今日がどの候かを計算し、その名前を縦書きで表示します。たとえば 10/28〜11/1 は「霎時施（こさめときどきふる）」です。
- **節気ごとの伝統色** 二十四節気ごとに伝統色をひとつ決め、その色で背景の絹のような流体（WebGL）を染めます。
- **時刻で変わる明るさ** 昼は明るく、夜は暗く沈みます。
- **候ごとの天気** 雨、雪、花びら、紅葉、蛍、霜のきらめきが画面を舞います。
- **集中タイマー** 終わるたびに、その日の回数を「正」の字で一画ずつ数えます。

## 操作

| キー | 動作 |
| --- | --- |
| Space | 集中タイマーの開始・一時停止（25 / 50 / 15 分は時間表示をクリックして切り替え） |
| ← → | ほかの候をめくって見る（「今」で戻る） |
| H | 文字を隠して絵だけにする |
| F | 全画面表示 |

「Now, I am」の後ろの一行はクリックして書き換えられます。内容はブラウザに保存されます。
